# Gadgets & Gizmos Wiki

Gadgets & Gizmos adds physics propulsion, kinetic control, programmable contraptions, ship automation, and utility tools for Create and compatible mods.

## Wiki Pages

- [Blocks and Interactions](Blocks-And-Interactions) - What each block and tool does, and how to configure it.
- [Advanced Control Computer](Advanced-Control-Computer) - Building node graphs, wiring values, and using inputs and outputs.
- [Ship Control Module](Ship-Control_Module) - Mapping a Sable ship, controlling it through an ACC, and using Shipping Schedules.
- [CC:Tweaked Bridge](CC-Tweaked-Bridge) - The documented CC:Tweaked peripheral and ACC graph API.
